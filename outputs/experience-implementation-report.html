01 / 已落地的任务流

/workspace稳定工作台

登录后固定落点；开始任务、最近会话、成果与能力快捷入口。

/sessions继续真实上下文

分页历史、错误重试；按真实 skill_id 与 session_id 恢复。

/skills发现 → 启用 → 使用

区分 ACL 可见、本人绑定与服务端可调用；未知状态不冒称就绪。

/results找回交互成果

先选来源会话，再读取授权摘要，返回原对话继续。

用户端：把断点变成明确状态

  • 共享登录入口，保留密码、OIDC、Google 的现有认证行为。
  • 历史恢复不再误用当前 Skill；失败、加载、空态和分页反馈分开。
  • 附件初始化或解析失败仍可编辑草稿，但所有模型触发入口继续校验附件。
  • 引用导入失败可真实重试；旧会话、旧账号请求不污染新上下文。
  • Skill 首次保存后接续实体 ID，后续保存使用更新，不重复创建。

管理端：配置事实，不冒充用户验收

  • /admin 显示真实 Root 配置、模型策略、双测试状态和资源接入入口。
  • 数据库动态模型实际切换统一要求 24 小时内有效的生成与工具调用测试。
  • 通用配置保存拒绝时为 422；专用使用接口保持 409。
  • 同模型其他字段保存、配置文件模型和既有别名不新增误拦。
  • 手机导航先到“就绪与资源接入”，再进入模型管理；旧 URL 保留。

成果接口的明确边界

GET /api/sessions/{session_id}/results

{
  session_id,
  results: [{ surface_id, title, kind,
              description, created_at }],
  state_available,
  incomplete_count,
  truncated
}
  • 先检查会话及 ACL，再以授权资源 owner 读取 SDK 会话状态。
  • 只读持久化 A2UI 交互成果摘要，不遍历全部聊天消息、不包含上传附件或 clientDataModel 正文。
  • 每会话最多 100 条；缺失、不完整、截断分别呈现，不冒称“没有成果”。

  • SDK 请求 num_recent_events=1，不保证所有后端只传输一条事件。

  1. 安全构建环境：在无旧产物的独立 checkout/CI 中走正常 next build；不关闭本机删除保护，不清理用户旧目录。本次未创建提交或执行远程 CI。
