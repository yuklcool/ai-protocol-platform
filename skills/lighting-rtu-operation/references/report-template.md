## 2. 固定要求

- 顶部标题默认使用普通文本标题，适配聊天正文与 Word 内容排版。
- 一级章节顺序固定，不得改名、删减、调序。
- “时间观察”“重点对象判断”“口径说明（重要）”“巡测异常样本（部分）” 为固定保留小节。
- “重点RTU”明细固定使用 Markdown 表格输出，列顺序为：RTU编号、RTU名称、报警数、首次报警时间、最后报警时间、报警类型；不得改回逐行描述格式。
- 默认不输出 SQL 附录；只有用户明确要求“附 SQL / 展示 SQL / 给我查询语句”时，才在正文最后追加 SQL 附录。
- 文本判断只允许基于真实数据变化，不得编造原因。

## 3. 默认时间口径

- “昨晚到今天早上 7 点” → 前一日 `18:00:00` 到次日 `07:00:00`

## 4. 巡测表口径约束

- RTU 夜间运行报告中的“07:00 时点运行状态说明”固定直接使用 **历史巡测表** `sl.r_his_coplog_phase`。
- 本模板不再使用 `sl.r_coplog_phase` 作为巡测/检测数据源。

## 5. 默认聊天正文 / Word 附件落地规则

- 报告生成完成后，默认先在聊天中返回正文。
- 若用户要求“附件”“Word”“可转发成品”，则生成 Word 附件交付。
- 若用户额外要求聊天内展示摘要，则可在发送附件同时保留摘要或正文。

## 6. SQL 输出规则

- 默认报告正文不输出 SQL。
- 只有用户明确要求“附 SQL / 展示 SQL / 给我查询语句”时，才在正文最后追加：`## 八、用于本报告的核心 SQL`。
- 追加 SQL 时保留“核心 SQL”概念，不改名，并按实际使用顺序附上。
