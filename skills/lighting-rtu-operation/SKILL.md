# RTU 运行

1. 调用 `query_lighting(request={"scene":"rtu","scope":"全系统"})`，可传精确 RTU 编号或名称。只用历史巡测，不用实时缓存代替历史证据。
2. 先说纳入 RTU 数、窗口有上报数、窗口无记录及末次采集失败对象。没有生产过期阈值不报在线/离线数或在线率；有上报也不代表三相、供电和所有回路正常。
3. 详情展示末次有效样本的 A/B/C 电压电流与采样时间，采集失败或无记录不能当零值。保留目标时点、来源与缺口。
4. 需要报警时加载 `lighting-rtu-alarms`，同一 RTU 和时间窗继续查询。没有历史下挂证据时，影响单灯数为未知。
5. “完整报告”保留原七章。聊天默认简短结论，要求正文时再输出服务实际报告，不伪造阈值、目标达成或原因。

详见 `references/business.md` 和 `references/runtime.md`。
