# 能耗四视图

按用户意图选 `query_lighting` 的参数，不能混用夜间和日报：

| 用户意图 | request |
|---|---|
| 昨夜与前夜同窗口 | `{"scene":"energy","energy_view":"night","scope":"全系统"}` |
| 最近一周RTU日报 | `{"scene":"energy","energy_view":"week","scope":"全系统"}` |
| 30日上升波动 | `{"scene":"energy","energy_view":"volatility","scope":"全系统"}` |
| 7日全系统节能率 | `{"scene":"energy","energy_view":"saving","scope":"全系统"}` |

服务自动定最近完整夜间或前7/30个已完成自然日；明确其他日期时传规范窗口。日报仅D。节能率固定全系统，不能把全系统指标当道路/设备指标；自定义口径另经 `sql-safe-query` 确认，不伪装成本原型支持的固定视图。

先解读真实数据，再给简短结论。夜间以累计巡测读数差为观测区间估算，明确首末样本与完整周期的差距。时长拆分只用同批有效配对、前夜时长>0，未匹配及复位样本不补齐；不是全网完整解释。

30日波动只将同时增加≥50 kWh且≥30%的点称为命中；前日必须是紧邻自然日，前日为0/缺失不算环比。服务返回全体有效/无效点，使用实际命中字段，不能把整张表都说成异常。

节能率先合计有效配对的理论/实际值再计算，不能平均每日百分比。系统记录为0而核算非0只叫指标一致性异常。目标缺失不能报达标。重复、负值、异常值和缺测分别说明，低耗不直接等于节能，高耗不直接等于故障。

趋势、日期联动、切换四视图和CSV由宿主提供，不生成其他HTML或重复卡片。详见 `references/business.md` 与 `references/runtime.md`。
