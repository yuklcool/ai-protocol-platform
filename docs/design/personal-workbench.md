# 个人工作台：对话优先

日常使用从普通对话开始，可连续追问、换话题和使用文件。同一会话可包含多个操作，操作结束不结束会话。现有 Root、模型服务、Skill、MCP、A2UI、知识库和认证权限继续使用原实现。

## 本次实现

- 主导航为对话、成果、资料、能力；最近八段会话与全部会话搜索统一放在侧栏。移动端复用主导航抽屉。
- 任务概览合并到 `/sessions`，原 `/workspace` 地址重定向到该页面。全部对话采用紧凑单列列表，首屏直接显示标题、更新时间和归档操作；顶部只有页面标题、新对话和搜索。日期与计划筛选按需展开，应用后收起并展示生效条件，可一键重置。会话本身不显示整体执行状态；实际计划放入折叠详情。
- 所有低频配置集中到 `/settings`，沿用管理员与平台管理员的不同可见范围及服务端授权。
- 资料页 `/documents` 复用上传、解析、文件夹、搜索与预览。点击“用于新对话”后通过受认证的文档接口读取元信息，等待会话附件加载后附加，附件沿用原持久化与解析门禁。
- 每段会话默认关闭预览。成果到达、操作开始、自动读取文件都不切换当前标签；消息内成果入口及文件点击显式打开预览。折叠面板不能获得键盘焦点。
- 工具活动折叠附在对应消息旁；成功的普通文本回复没有运行卡，失败、中断和停止仍明确展示。
- 会话列表提供所有者归档，调用现有软删除接口；失败保留记录并显示错误。账号切换重建最近会话列表，防止旧请求回填；切换会话重建会话运行视图，首条消息写回同一会话 ID 时不重建。

## 验证

本地仅编辑。GitHub CI 运行 lint、类型检查及单元测试；现有 Model provider gate 构建生产前端并运行 Chromium 验证。新增覆盖最近会话的账号隔离、归档失败及取消、普通问答与异常回复、新建对话时清除旧会话、按需打开成果、历史 A2UI 单次挂载，以及资料上传至新对话的附件保存和刷新。

协议 fixture 的浏览器测试验证真实前端组件与消息事件，不代表外部模型或供应商已验收。

会话列表的浏览器验收额外检查：1440、768、390 像素宽度下，默认首屏完整显示至少六条会话；日期筛选应用后首屏至少显示五条结果。保留服务端分页、日期边界、无匹配、单条会话、计划筛选及归档取消检查，并生成实际页面截图。
