## 数据与安全

任务状态只投影助手明确报告的最新业务计划，不使用 RUN_FINISHED 推断成功。新计划在既有持久化回调中更新会话索引；旧会话在所有者读取历史时回填。未回填或未报告计划的会话为 unplanned。它不是后台任务引擎；刷新恢复状态，不自动执行或恢复外部工具。

成果页按服务器会话搜索分页，每页读取 20 个来源会话。搜索覆盖全部历史标题与编号，不搜索成果正文。每会话的交互摘要仍保留 100 条限制及损坏/不可用提示。上传附件不算成果，不把空状态、错误、未就绪当成功。

文本报告复用现有文档 Repository，通过不可变版本的原子创建实现跨进程冲突检测。报告从对话文本显式创建和编辑，不伪装成模型重新生成；读取与 TXT 下载复核来源会话 ACL，保存仅限活动会话所有者。没有 SQL 表迁移、新运行时或额外依赖。删除/归档会话后不再出现在成果搜索中。

一次性确认以服务端保存的表面类型为准，原子占用 session + surface；不同浏览器窗口不能再次执行同一确认。通用 A2UI 允许新请求重复操作，但相同请求 ID 不重放。保留外部工具结果不确定时的人工核对：继续按钮恢复草稿，用户核对后明确发送。该保护不保证外部工具事务恰好执行一次，也不自动回滚副作用。

配置向导复用现有页面和 API。进入下一步前在原表单保存；步骤编号不表示通过。最后一步从服务器读取配置一致性和模型双测试记录，不把“已填写”当“已验证”。MCP、用户权限和真实业务验收仍各自按实际任务验证。
