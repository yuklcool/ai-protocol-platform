# 任务对话布局修复

来源：用户反馈新会话输入框居中、下方大块留白、消息不可见。延续 DESIGN.md 的银白、石墨、操作蓝与系统字体，不新增设计系统或依赖。

## 调整

- 新会话、首条发送、流式回复和恢复历史共用同一消息区及底部输入框，不再在首条消息时切换或重新挂载输入区。
- 消息从顶部开始排版，正文与输入区采用同一最大阅读宽度；消息区独立滚动，输入区固定在聊天面板底部。文件面板及复杂成果 Workbench 继续使用原有入口。
- 附件入口收进输入框工具区，文件格式限制按需展开；进度、解析错误、重试和原有授权逻辑保留。知识库上传继续使用原有完整上传区。
- 恢复会话时明确显示消息加载状态；加载失败或历史正文不可用时给出提示，不再同时显示新会话引导。

参考 [Claude 的附件入口](https://support.claude.com/en/articles/8241126-upload-files-to-claude) 和 [ChatGPT 对话内文件操作](https://openai.com/academy/working-with-files/)，只借鉴输入区组织，不引入它们的文件类型或容量承诺。
