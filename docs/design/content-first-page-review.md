# 全站页面内容优先排查

范围：个人工作台、配置管理、认证入口与协议调试页。沿用银白浅色、系统字体和现有组件，不增加 UI 依赖。页面先展示资料、成果、列表或真实状态，重复介绍和低频表单按需展开。

| 页面 | 排查结果与处理 |
| --- | --- |
| `/sessions`、`/workspace` | 紧凑标题和搜索工具栏、单列会话行，日期和计划筛选按需展开；保持分页、归档确认与错误反馈。`/workspace` 沿用重定向。 |
| `/results` | 去掉介绍大区块与双列来源卡片。确认完整且没有成果的来源不显示空卡；状态未知或不完整统一收进“需核对的来源”入口，展开后可逐条核对，实际成果优先展示，读取失败明确报错。保留来源搜索、分页、报告编辑、版本保存和授权下载。空页只代表已检查的会话，不推断更早会话。 |
| `/documents` | 紧凑上传入口，格式限制按需展开，资料列表提前。手机文件预览排在列表上方并获取焦点，关闭后返回列表；桌面保留分栏。上传任务、解析失败及重试仍可见。 |
| `/skills` | 移除装饰性副标题，说明合并折叠，减小卡片空白，长名称允许换行。保留服务端可用性检查、所有者权限、个人启用和 Studio 开关。 |
| `/settings` | 独立大卡片改为紧凑设置行；权限仍由原有管理范围过滤。 |
| `/settings/personal` | 将重复说明横幅收为辅助文字，保留专有 Skill、个人信息与明确保存反馈。 |
| `/setup` | 压缩标题，移除嵌入模型/MCP 页重复标题与返回导航；复用原表单及四步就绪检查，不建立第二套配置。 |
| `/agent` | 保留分区编辑和保存；移除每个分区重复显示的通用介绍。 |
| `/admin/knowledge` | 先显示来源，上传与添加表单放入折叠区；手机操作允许换行。保留分享范围、解析状态、绑定草稿、显式保存、检索和删除确认。 |
| `/admin/mcp-servers` | 默认显示服务列表，新增/编辑时展开表单，手机将表单提到列表前；打开聚焦标题，关闭/保存返回入口。修复刷新列表覆盖保存、删除与启停成功提示的问题；保留凭据只写语义和双诊断。 |
| `/admin/model-providers` | 简化说明，将默认模型摘要收紧，去掉同一模型的重复展示。保留连接、发现、双测试、驻留策略及显式应用。 |
| `/admin` | 去掉重复语言开关，将功能入口放在完整就绪清单前；配置向导仍可直接进入。 |
| `/admin/diagnostics` | 复用更新后的就绪组件；手机优先模型验证状态，详细配置流程折叠。服务健康与模型/工具验证继续分别反馈。 |
| `/admin/users` | 新建账号表单默认折叠，现有用户表格提前；密码规则、个人配置、停用与权限检查保留。 |
| `/admin/analytics` | 修复宽度类冲突导致筛选器竖排的问题。手机统计采用两列，用户/模型明细及统计口径折叠，缺失定价告警保持可见，费用仍使用 USD。 |
| `/admin/audit` | 已有紧凑记录表与可展开详情，保留；继续检查手机局部横向滚动和详情操作可达性。 |
| `/admin/settings` | 公共指令和上下文压缩为实际编辑内容，保留完整字段、草稿状态、保存和风险提示；检查溢出与手机操作。 |
| `/skills/studio/new`、`/skills/studio/[skillId]` | 简化顶部说明，缩小参考资料折叠入口；保留能力正文编辑空间、文件、访问控制、保存和放弃草稿确认。 |
| `/`、登录弹窗 | 首页为公开介绍、登录弹窗为认证表单，保留；检查三种宽度、登录失败和键盘焦点。 |
| `/auth/oidc/callback` | 错误反馈补充返回首页重新登录入口，避免错误页无路可走。 |
| `/group` | 现有模式不启用时已明确提示并提供返回入口，保留；不改变认证模式。 |
| `/dev/a2ui`、`/dev/mcp-apps`、`/dev/mcp-apps/active` | 调试说明属于必要上下文，保留；继续检查宿主布局和独立源沙箱。 |
| `/dev/mcp-apps/passive` | 修复连接失败后一直显示连接中、留下空白容器的问题；显示错误与显式重试，连接成功才挂载对应表面，离开时关闭客户端。 |

## 验收

- 本地只编辑与阅读源码；所有测试、类型检查、构建、服务和浏览器运行在 GitHub Actions。
- `ui-responsive-live.spec.js` 覆盖 25 条主路由的 1440、768、390 三档视口，并另验首页、登录失败和 OIDC 错误。
- 内容密度回归检查紧凑标题高度、资料列表首屏位置、用户表格首屏、知识来源先于添加表单、用量筛选同排和指标首屏。
- 交互回归包括 MCP 新增/编辑/删除与焦点、知识来源折叠、用户创建、手机预览、报告编辑保存及授权下载。测试账号、文件和服务均为隔离的合成数据。
- 单测覆盖确认空成果与未知状态区别、会话丢失告警、权限边界、配置流程展开和协议示例失败重试。
- 当前提交的检查和浏览器证据通过 [PR #151](https://github.com/yuklcool/ai-protocol-platform/pull/151) 查看；历史截图不替代当前提交验收。
