# 可直接复用的页面设计提示词

将下面内容与具体产品需求一起使用。如果同时提供 `theme.css` 和 `index.html`，以文件中的真实参数和效果为准。

---

请将页面设计为 CopilotKit Generative UI Playground 参考中的浅色玻璃拟态风格。整体应柔和、轻盈、清晰，保留淡紫与薄荷绿的视觉组合。

**配色：**以 `#F7F7F9` 为浅底，背景向 `#DEDEE9` 过渡。主点缀为淡紫 `#BEC2FF`，辅助点缀为薄荷绿 `#85E0CE`。主文字 `#010507`，次文字 `#57575B`，辅助文字 `#8E8E93`。大面积保持白色与浅灰，把彩色留给柔焦背景、少量标题、主要按钮和分类图标。

**背景：**固定全屏浅灰渐变，右上淡紫光斑、左下薄荷绿光斑，中央可叠加更淡的紫绿光斑。光斑模糊约 `80–100px`，透明度约 `.4–.6`，以 `25–35s` 周期轻微位移和缩放。手机缩小尺寸与模糊半径；系统要求减少动态效果时关闭动画。

**内容容器：**使用白色 `70%` 透明度、`backdrop-filter: blur(12px)`、`1px solid rgba(255,255,255,.3)` 边框、`16px` 圆角。卡片内边距 `20–24px`。阴影柔和克制。功能卡片悬停上移 `4px`，顶部显现 `3px` 淡紫到薄荷绿渐变线。只在需要强调的容器使用较明显阴影。

**排版：**英文使用 Google Sans，中文回退微软雅黑、苹方或系统无衬线字体；离线交付时内嵌字体。标题桌面 `36px`、手机 `24px`，字重 `700`；卡片标题 `18px / 600`；正文 `16px`、行高 `1.6`；说明和标签 `14px`；辅助文字 `12px`。代码与数字参数可用系统等宽字体。

**布局：**页面内容宽约 `768px`，桌面外边距 `32px`、手机 `16px`；按 `4px` 基础单位组织间距。顶部标题和简短介绍居中，下面依次排列模式切换、功能卡片和详情内容。卡片间距 `24px`，手机一列、平板两列、宽屏四列。工具型页面可在右侧配置简洁白色助手面板，手机改为折叠或弹出式交互。

**控件：**模式切换用圆角标签，选中项纯白底并带轻阴影。快捷操作使用白色 `50%` 的胶囊，`24px` 圆角、`12px 16px` 内边距，悬停边框变淡紫。主要按钮用 `#9F8FEF → #7DD3C0` 水平渐变、白字、胶囊形。渐变标题使用更深的 `#9599CC → #1B936F`，与按钮渐变分别处理。

**图标与动效：**分类图标放在 `48px` 方块中，圆角 `12px`，白色线框图标搭配蓝、紫、琥珀或绿的类别底色。控件状态过渡控制在 `0.2–0.3s ease`。提供明确的键盘焦点和禁用状态。

保留现有产品信息和功能，不因参考样式而机械复制介绍文案或页面结构。使用普通 CSS 变量统一管理颜色、间距、圆角与阴影，优先复用现有组件。
