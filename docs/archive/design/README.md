# 历史版本设计归档

这里保存上游 v6 各阶段的设计、计划和实现记录。其代码路径、默认基础设施、状态和验收结论可能已经变化。

当前操作从[完整配置流程](../../configuration-guide.md)开始；模块职责见[模块边界](../../module-simplification.md)。当前发布与未完成工作见[交接状态](../../../HANDOFF.md)。

归档没有保留原目录副本或跳转文件。代码及文档引用已更新；被删除、未实现或未随仓库分发的目标保留为普通历史路径文本，避免制造可点击的失效链接。历史设计不进入文档助手的默认检索语料。

仍在使用的 ADK 约束可参考[契约检查清单](v6.17.0/adk-contract-checklist.md)，并以对应测试为准。
