# 协议操作验收

| 路径 | 验收内容 |
| --- | --- |
| Root / AG-UI | 普通聊天、工具往返、终态、取消与失败事件 |
| Skill | 公共与个人能力目录、延迟加载、撤销即时生效 |
| MCP Apps | 注册、握手、工具/资源发现、Agent 绑定、代理与独立源嵌入 |
| A2UI | 表单操作、状态持久化、刷新恢复、操作触发运行 |
| 附件 | 当前轮选择、取消选择、解析失败、跨用户拒绝、模型输入 |
| Session / Memory / Artifact | 用户所有权、app 状态隔离、重启持久化 |

本地回归不连接外部数据库和模型。真实 Provider 与浏览器工作流使用独立测试账号及临时资源，完成后恢复 Agent 配置。

目标部署验收使用两个不同的已验证 UID。客户端传入 UID、角色或资源 ID 不能授予额外访问。管理员读取其他用户的会话先校验管理权限，再显式选取已授权的资源所有者。

配置和升级行为见 [配置流程](configuration-guide.md)，真实模型设置见 [真实 Provider 验收](real-provider-acceptance.md)。
